# Libraries, Gradle plugins and CI tools the owner has approved (spec LIC-3).
#
# tests/check_dependencies.py fails when a library or plugin in android/gradle/libs.versions.toml, or a
# direct dependency of the release or debug app or of the unit tests, matches no entry here. Gradle files
# must declare every dependency and plugin through the catalog, so each one gets checked. A new
# dependency needs the owner's approval first, with its licence named; then it gets a line here in the
# same change.
#
# One entry per line, four columns separated by "|":
#   pattern | licence (SPDX) | date approved (YYYY-MM-DD) | what it is
# Patterns:
#   group:artifact    a Maven library. "*" matches any run of characters inside the group or the
#                     artifact, never across the ":".
#   plugin:id         a Gradle plugin from the catalog's [plugins] table. "*" matches any characters.
#   ci:name           a Python package that only CI runs. It never ships and approves no library.
#   !group:artifact   never allowed in the build, not even when an approved library pulls it in. The
#                     licence column of such a line is "-".
# A line that starts with # is a comment.
#
# Libraries that an approved library pulls in under a permissive licence (Apache-2.0, MIT, BSD, ISC) are
# accepted without an entry here (owner decision, 2026-11-14). The AboutLibraries licence check in the
# app's build fails on any other licence (LIC-2). It doesn't see test-only libraries, so their licences
# are checked by hand. config/resolved-dependencies.txt lists every library the app ships, and what the
# debug build and the unit tests add, so each new one shows up in the pull request's diff. The owner
# approved these by name on 2026-11-14: Ktor and the SLF4J API (MIT) through RootEncoder; JSpecify,
# JetBrains annotations and Guava's listenablefuture through AndroidX and Kotlin.
#
# Native libraries (libsrt, OpenSSL, libuvc, libyuv, libjpeg-turbo) have no Maven coordinates. Their
# licence entries are written by hand in config/aboutlibraries/.
